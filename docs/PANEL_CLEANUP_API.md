# حساب تک‌کاربر و حذف مراحل پنل — 2026-10-06

اصلاح جاری2026-10-17: بخش تاریخی ورود/ثبت‌نام پایین با [REGISTRATION_API](REGISTRATION_API.md) جایگزین شده است: verify فقط ورود، register مستقل با ایمیل/نام/نام خانوادگی و معرف اختیاری. قواعد تیم جاری در [TEAM_MOBILE_API](TEAM_MOBILE_API.md) هستند؛ محدودیت تاریخی حذف تیم پایین جاری نیست.

این قرارداد بخش ورود و تیم در راهنماهای قدیمی را جایگزین می‌کند. Angular در این ریپو نیست؛ عنوان فارسی Swagger حفظ شده است.

ورود/ثبت‌نام فقط موبایل است: `GET /api/auth/csrf` → `POST /api/auth/otp/request` با mobile → `POST /api/auth/otp/verify` با mobile/code. CSRF، Bearer، کوکی refresh، rotation و logout/logout-all قرارداد قبلی را دارند. فقط حساب فعال Owner با موبایل تأییدشده به پنل دسترسی دارد. موبایل تازه سازمان مستقل خود را می‌سازد؛ پیوستن به سازمان دیگر وجود ندارد. نام حساب و سازمان با PUTهای me/organization تغییر می‌کند؛ Email nullable در me صرفاً metadata تاریخی است.

مسیرهای register، login ایمیلی، confirm-email، resend-confirmation، forgot-password، reset-password، change-password، auth/invitations/accept و همه api/members حذف شدند. SMTP و Mailpit از runtime/config/Compose حذف شدند. صفحات ایمیل/رمز و منو/دعوت تیم را از فرانت حذف کنید. این حذف شامل **دعوت کارجو** نیست؛ آن قابلیت باقی است. Dashboard دیگر activeMembers و pendingInvitations ندارد.

| درخواست | رفتار |
|---|---|
| `DELETE /api/job-positions/{id}` | حذف منطقی موقعیت و قالب‌های متعلق به همان موقعیت از پنل |
| `DELETE /api/interview-templates/{id}` | حذف منطقی همان قالب و سؤال‌هایش از انتخاب پنل |
| `DELETE /api/interviews/{id}` | حذف منطقی مصاحبه، ابطال دسترسی کارجو و lease، تسویه مصرف و آزادشدن باقی رزرو |

Bearer مالک سازمان لازم است؛ body ندارد؛ موفقیت 204 و شناسه ناشناخته/سازمان دیگر/قبلاً حذف‌شده 404 است. موارد حذف‌شده از فهرست، جستجو، جزئیات مدیریتی و آمار خارج‌اند و با PUT برنمی‌گردند. حذف فیزیکی تاریخچه/فایل و API بازیابی اضافه نشده‌اند. پس از 204 فهرست/داشبورد را reload و انتخاب مورد حذف‌شده و مراحل وابسته را پاک کنید.

موقعیت/قالب حذف‌شده برای دعوت تازه قابل استفاده نیستند؛ ساخت/ویرایش قالب روی موقعیت حذف‌شده 404 است. دعوت صادرشده قبلی با snapshot خودش ادامه می‌دهد؛ حذف والد، کارجو را ضمنی لغو نمی‌کند. برای توقف دسترسی خود مصاحبه را حذف/لغو کنید. قالبی که قبلاً برای موقعیت دیگری کپی شده مستقل است. حذف سؤال از قالب با PUT فهرست سؤال‌های جدید انجام می‌شود؛ حداقل پنج سؤال ویزارد حفظ است. برگشت مرحله یا رهاکردن فرم رکورد ذخیره‌شده را خودکار حذف نمی‌کند.

حذف مصاحبه شروع‌شده، مصرف پاسخ‌های persistشده را فقط یک بار تسویه و باقی رزرو را آزاد می‌کند. حذف مصاحبه تکمیل‌شده مبلغ قبلی را تغییر نمی‌دهد. نام کارجو/مصرف/پرداخت/فاکتور در سوابق مالی باقی‌اند. cancel/revoke قدیمی عملیات مستقل با رفتار قبلی‌اند. حذف حین AI جلوی evidence دیررس را می‌گیرد. پس از حذف، resume/report/audio مدیریتی 404 و توکن کارجو نامعتبر است؛ درخواست دانلودی که پیش از حذف آغاز شده ممکن است همان پاسخ در حال ارسال را کامل کند.

Migration `20261006071854_SimplifyAccountsAndPanelDeletion` ستون‌های DeletedAtUtc و محدودیت یک Owner فعال در هر سازمان را اضافه می‌کند. Recruiterهای تاریخی غیرفعال، refreshهایشان باطل و دعوت‌های تیم معلق لغو می‌شوند؛ رکوردها برای حفظ سابقه و سازگاری schema باقی‌اند. rollback این غیرفعال‌سازی/لغو را خودکار برنمی‌گرداند.

Owner ایمیلی قدیمی بدون موبایل تأییدشده بعد از انتشار دسترسی ندارد؛ قبل از انتشار با بررسی مالکیت، شماره معتبر را به **همان حساب و سازمان** متصل کنید. تطبیق حدسی با ایمیل یا ساخت سازمان تازه انتقال سوابق نیست. OTP روی شماره متصل به حساب قدیمی همان حساب را تأیید می‌کند. انتقال داده واقعی در این نوبت انجام نشده است.
