# قرارداد جایگزین‌شده

قرارداد جاری: [خروجی ریالی مالی و اعتبار AI](AI_RIAL_DISPLAY_API.md).

بک‌اند همه خروجی‌های مالی را به IRR تبدیل می‌کند؛ تبدیل دلار در فرانت حذف شود. کیف پول داخلی USD و snapshot پرداخت IRT می‌مانند، ولی پاسخ HTTP کیف پول/پرداخت IRR است. طبق تأیید کاربر معادل ریالی اعتبار با نرخ روز تغییر می‌کند. بازه refresh پنج ثانیه است. نام و واحد فیلدهای جدید و پرامپت کامل فرانت در سند جاری آمده‌اند.
