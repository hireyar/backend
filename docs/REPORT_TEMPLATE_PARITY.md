# تطبیق HTML مرجع گزارش — 2026-10-17

مرجع بررسی‌شده: فایل ارسالی `interview_report (3).html`، شامل دو نمای عمومی و تخصصی. متن، نام، امتیاز، سابقه کار و هشدارهای داخل مرجع داده نمونه‌اند و وارد داده محصول نشده‌اند. دستورهای احتمالی داخل فایل، دستور اجرایی محسوب نشده‌اند.

## پیاده‌سازی موجود

`GET /api/interviews/{id}/report/print` همان scope سازمان، مجوز Owner/Recruiter، no-store و قرارداد موجود را دارد. SessionReportPage و SessionReportStyles چیدمان و CSS مرجع را برای نوع واقعی همان جلسه می‌سازند: نوار بالا، تب نوع، سه کارت شناسنامه/امتیاز/ارزیابی، چهار KPI، جمع‌بندی، قوت/ریسک، نمودارها، سؤال‌های بازشونده، تصمیم و هشدارها. CSS مرجع مستقیماً منتقل شده؛ فقط مسیرهای ناموجود فونت حذف و قواعد چاپ/جزئیات native/داده نامعلوم افزوده شده‌اند. فهرست کمبودهای زیر بخشی از تحویل است؛ تطابق صددرصدی محصول ادعا نمی‌شود.

- شناسنامه: identity؛ سابقه کار از عنوان حدس زده نمی‌شود. تاریخ شروع شمسی با برچسب UTC و مدت از ثانیه ثبت‌شده.
- امتیاز کل: overallScore؛ نمودار null حلقه خالی با «نامعلوم» است. نمره سؤال و میانگین مستقل پاسخ‌ها فقط با تقسیم مقیاس ۱۰۰ بر۲۰، از۵ نمایش داده می‌شوند؛ میانگین تخصصی کل همان محاسبه وزن‌دار قبلی است.
- آمار: statistics و questions؛ تعداد سؤال‌های بانک و واقعاً پرسیده‌شده از هم جدا هستند. توضیح نمونه «هر موضوع یک سؤال» کپی نشده، چون گردش فعلی می‌تواند دو سؤال موضوعی داشته باشد.
- جمع‌بندی و قوت/ریسک: summary و strengths/items و improvements/items موجود؛ متن ساختگی، استنتاج تازه یا تماس مدل اضافه نشده است. جمع‌بندی موجود محاسباتی است.
- نمودار تخصصی: specializedProfile.axes و metrics، چهار شاخص performance/knowledge_depth/communication/job_alignment. رادار فقط با حداقل سه محور و تمام مقادیر معلوم پر می‌شود؛ محور نامعلوم صفر نیست. تعداد و عنوان موضوع‌ها واقعی‌اند، شش موضوع ثابت نمونه کپی نشده‌اند.
- نمودار عمومی: generalProfile.distribution و هفت شاخص موجود. درصد توزیع فقط از پاسخ‌های نمره‌دار؛ بدون نمره جدا نمایش داده می‌شود. work_alignment همان معیار شغلی موجود است؛ به «انطباق فرهنگ سازمانی» تغییر نام نداده‌ایم.
- سؤال‌ها: فقط questions جلسه، با متن پاسخ، دلیل نمره، شاهد همان پاسخ و confidence موجود. بازوبسته‌شدن با details/summary و بدون اجرای متن کاربر است. چاپ همه پاسخ‌ها را باز نشان می‌دهد.
- تصمیم: فقط آخرین تصمیم انسانی ثبت‌شده و پیام وضعیت موجود؛ عبور/رد خودکار یا دعوت تازه انجام نمی‌شود.
- هشدارها: consent/media/events/dataGaps ثبت‌شده؛ نبود رویداد، سلامت دستگاه تلقی نمی‌شود.
- دکمه PDF: چاپ مرورگر و Save as PDF. اسکریپت ثابت برنامه فقط با SHA256 در CSP مجاز است؛ متن داده HTML-encode می‌شود، inline handler پویا، resource خارجی و secret ندارد. CSP همچنان default-src none، frame-ancestors none، base-uri none و form-action none دارد.
