# قرارداد جاری

[اعتبار ثابت ریالی، رزرو هنگام دعوت و مصرف دلاری خصوصی](RIAL_AI_WALLET_API.md) قرارداد جاری است و توضیح تاریخی «اعتبار دلاری با معادل ریالی متغیر» را جایگزین می‌کند.

کیف پول، شارژ، ledger و مصرف واقعی IRR هستند؛ نرخ فقط هنگام ایجاد دعوت برای رزرو snapshot می‌شود. لندینگ پویا و نرخ صفحه دعوت در پنل کارفرما هر۵دقیقه تازه می‌شود؛ در قطعی سرویس ثالث با پاسخ200 آخرین نرخ معتبر حفظ می‌شود و retry فوری فرانت لازم نیست. تا اولین دریافت معتبر، بک‌اند تلاش مجدد می‌کند. کارجو هیچ اطلاعات مالی نمی‌بیند. مصرف دلاری فقط در دیتابیس نگهداری می‌شود و در پاسخ سوابق مالی نمایش داده نمی‌شود. قرارداد و پرامپت کامل فرانت و دستور migration در سند جاری آمده‌اند.
